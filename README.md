## Problem Idea
This project is focused on building foundational skills in NumPy and pandas for machine learning workflows. We are practicing data manipulation, descriptive statistics, and reproducibility concepts (random seeding) using small toy datasets. A specific real-world prediction problem will be defined in a later stage of the project.

## Dataset Status
No external dataset has been sourced yet. So far, this project has used small, manually created toy datasets for practice: a NumPy array of 6 sample marks, and a 6-row pandas DataFrame simulating student study habits (study hours, sleep hours, attendance, snacks) with a pass/fail label. These were used to practice NumPy and pandas operations, filtering, sorting, and descriptive statistics.

## How to Run the Notebook

**Option 1 (recommended): Google Colab**
Open `notebooks/lab01_setup.ipynb` directly in Google Colab via File → Open notebook → GitHub tab, then paste this repository's URL.

**Option 2: Run locally**
1. Clone this repository:
   ```
   git clone https://github.com/rimonkumardas22-cmyk/ml-project-lab01-foundations.git
   ```
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Launch Jupyter and open `notebooks/lab01_setup.ipynb`.
4. Run all cells in order from top to bottom.
